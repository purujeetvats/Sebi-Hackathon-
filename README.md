# SEBI Hackathon Project

This is a small static web project. To start a local dev server and open the app:

- Using Node (recommended):

```bash
npm run start
or
npm run dev
```

This runs `npx http-server` on port 8080. If you don't have Node, you can use Python:

```bash
cd /Users/kunalchoubey/Projects/SEBInewfile
python3 -m http.server 8080
```

Open http://localhost:8080 in your browser.

Project files of interest:

- [index.html](index.html)
- [app.js](app.js)
- [styles.css](styles.css)

Dev (local installed):

```bash
npm run dev
```
